# V1.0 补充功能验收

从同一交付提交下载 Android APK 或 Windows 完整运行目录。Windows 解压完整目录后启动应用。先创建包含当前周的学期、两门同名课程及不同教学班的导入样例。跨平台恢复测试使用合成数据和测试票据。

| Issue | 入口与操作 | 通过条件 |
| --- | --- | --- |
| #40 周课表 | 日程顶部打开周课表，跳到上一周和下一周，点日期回日视图 | 同一日期的时段与日视图一致，跨日事项在两天可见，点击能打开原记录 |
| #41 待办 | 总览顶部打开待办，切今天、七天内、逾期，组合课程或类型 | 同一任务只出现一次。无时间的任务只出现在全部。已完成任务和已提交作业移出。考试独立显示 |
| #42 作业状态 | 学业 → 课程 → 作业，将同一作业依次切为进行中、已提交、未开始 | 待办和总览同步，退出重开后仍显示最后一次保存的状态 |
| #43 搜索 | 总览顶部搜索中文标题、英文大小写、账目备注和分类 | 同名记录分别显示，点结果打开对应记录或账目月份，返回保留查询 |
| #44 撤销 | 分别删除任务、事件、作业、考试和带票据的收支记录，点撤销 | 原 ID、字段、状态、关联及票据恢复。原课程或分类已删除时提示恢复失败 |
| #45 课程详情 | 学业点课程，查看课程时间、教师、地点、关联作业和考试 | 改名后关联仍正确，0 绩点与未评分可区分 |
| #46 调停课 | 点日程或周课表中的一次课，选仅修改这一次，改日期和教室，再停课和恢复 | 原日期移除，目标日期仅出现一次，其他周保持原安排。影响已有调停课的常规调整或重新导入给出提示 |
| #47 复制 | 从任务或事件菜单复制，明确选目标日并编辑草稿，分别测试取消和保存 | 仅保存后生成新 ID。跨午夜时长保留。原记录不变，副本任务和子步骤未完成 |
| #48 优先级及子步骤 | 编辑任务，修改优先级，增加、重命名、勾选和删除子步骤 | 重启后仍保留，待办优先级排序正确，子步骤状态和父任务完成状态分别保存 |
| #49 账目筛选 | 生活账本右上角打开筛选，组合收支、分类及跨月日期范围 | 包含首尾日期，数量和整数分合计与筛中记录一致。月预算仍按原月份统计 |
| #50 报销票据 | 添加支出时展开报销与票据，选择 JPEG 或 PNG，切换报销状态 | 支出金额不变，待报销筛选正确，重启能打开票据。收入无报销控件。单笔支持一张不超过 1 MB、边长不超过 4096 像素的票据 |
| #51 完整备份 | 总览顶部备份与恢复 → 导出，在另一端选文件，核对预览数量，确认整体替换 | 任务、学业、日程、账本、预算、票据和调停课均可核对。取消和损坏文件保留本地数据。恢复成功后应用目录留存恢复前快照 |

备份为包含 SHA-256 校验的版本化 JSON 文件。恢复上限 64 MB。教务登录会话存放在独立的 WebView 环境中。Android 与 Windows 的系统文件选择、窄屏软键盘、真实华师教务登录和跨设备恢复由实机记录。
