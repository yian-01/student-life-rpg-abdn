# 课屿材质与动效改版

依据用户提供的七张界面设计参考，落实材质、动效、空间感、统一组件四层设计。

| 参考方向 | Flutter 实现 |
| --- | --- |
| 玻璃、细边框、柔和阴影 | GlassSurface、局部 BackdropFilter、统一 surface/border tokens |
| 网格渐变、颗粒质感 | 背景 CustomPainter，固定随机种子的微粒与柔和网格光照 |
| 立体球、轨道、视差 | Canvas 上实际三维坐标旋转与透视投影，指针控制视差 |
| 滚动渐入、交错动画 | 懒构建区域的有限时长 SurfaceReveal，依序错开时长 |
| 按钮反馈、平滑过渡 | 卡片按压缩放、悬停提起与边框反馈，路由淡入与位移 |
| 组件一致性、完整状态 | 统一主题中的按钮、输入、弹窗、导航、提示条、卡片；原有加载/错误/空状态与重试保留 |

保持现有 Flutter 架构，不引入 React、CSS 组件库或 Three.js。球体是 Flutter Canvas 的三维投影绘制，并非 Three.js/WebGL 场景。入口动画结束后停止，不设置永久运行的粒子动画。系统“减少动态效果”关闭入口、视差和按压位移动画。

首页全部指标继续读取当前账号的真实仓库，无演示曲线、假增长率或假同步成功。支持顶部搜索按钮和键盘 Ctrl/⌘+K 打开功能面板，输入关键词筛选、回车打开；面板内也提供原有的全站记录搜索入口。个人空间仅保留原有卧室场景。

交付沿用已有前端校验、备份和回滚更新脚本，API、账号库和 .env 不在此 UI 改版中修改。
