# 课屿校园生活界面

首页由卧室场景改为日常生活概览。卧室仍可从首页「我的小小空间」和「我的 → 我的空间」进入，并可返回原页面。

## 导航与信息

| 入口 | 内容 |
| --- | --- |
| 首页 | 日期、今日计划、课程管理、待办、专注、GPA、当月收支、今日课程 |
| 课表 | 已有日程手账、周课表、任务与作业入口 |
| 记账 | 已有账本、分类、预算及收支记录 |
| 我的 | 账号与同步、学业、课程、事件、统计、个人空间、备份 |

首页所有指标使用当前账号的真实仓库，不注入演示课程、金额、成绩或同步成功状态。没有成绩时不把 GPA 显示为 0；没有记录时提供明确的空状态和新建入口。各分区独立显示读取失败及重试。从数据编辑页返回及应用回到前台时重新读取，下拉也可刷新。

## 视觉

- 海蓝 `#16697A`，浅灰背景 `#F7F9FA`，白色卡片，深色正文 `#183A45`。
- 页面内容采用清晰标题、适度间距和统一圆角，工具页面移除木框和背景场景。
- 320、390、1200 逻辑像素宽度验证；窄屏卡片可换行。
- 功能入口支持点击与键盘焦点，图标按钮有用途提示。

## 验证与交付

`frontend/test/app/platform_home_test.dart` 验证真实空状态、待办读取、返回后的刷新、固定导航与多宽度溢出，并输出 `frontend/build/interface-review/` 截图。

`frontend/test_web/account_sync.cjs` 从新首页进入账号页，继续验证编译版登录、退出时清除账号缓存及再次登录后的云端恢复。

`.github/workflows/keyulife-interface.yml` 负责分析、全量测试、Web 编译、浏览器账号恢复验证和预发布包。只有上述步骤通过才发布可安装的前端版本。

## 在现有服务器更新

使用对应预发布版本的 `update-interface.sh` 附件，不直接运行含占位符的源模板。脚本固定校验对应前端 ZIP 的 SHA-256，检查文件结构，备份原 `site` 目录后替换，仅重建 HTTPS 容器以更新目录挂载，并验证公开 HTTPS 健康接口。失败会恢复原界面。

账号数据库、API 容器和 `.env` 不由前端更新脚本修改。更新后在浏览器重新加载首页。发布包并不表示现有香港服务器已自动更新。
