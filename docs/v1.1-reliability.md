# V1.1 账号与同步修复、验收矩阵

核验日期：2026-11-21。基于真实预览代码 `6d1178ee3b71786e9a37fdb4559d8818f8bf0b4e`，开发分支 `fix/v1.1-reliability`。

开发顺序为：V1.0 / V1.1 功能代码 → 手机与桌面 UI → 大模型功能 → 联合验收与正式发布。本轮不发布安装包、不合并重要 PR、不更新 keyulife.cn。

## 本轮修复

- Web 请求原本强制同源，且只把路径交给浏览器，忽略 API 的独立主机。现可在 Web、Windows、Android 构建时配置同一个 `CAMPUS_SYNC_URL`；Web 默认仍可使用当前来源。
- 后端增加精确来源白名单、OPTIONS 预检和 ETag 暴露。允许来源仍需 Bearer 认证；无 Origin 的原生客户端仍正常认证。跨域不依赖 Cookie，也不要求各平台使用同一前端域名。
- 同一账号从云端拉取新数据后，首页缓存的 Future 原本不会更新。新增数据修订通知，刷新已有首页，无需切换页面。访客导入也发送通知；空同步不增加修订。
- 账号切换或退出时清除 Flutter 的全局图片缓存及 live image 引用，覆盖票据预览。
- 修复首页标语在窄屏和放大字体下的溢出，保留现有业务布局；整体 UI 设计仍属于后续阶段。
- 原生端到端测试可通过 `PYTHON` 指定解释器，Windows 默认使用 `python`，避免命中不可执行的 `python3` 商店别名。
- 接入 V1.0 已验证的 Android 签名保护：常规 release 缺少密钥时拒绝构建，临时验收签名必须显式启用。没有生成长期密钥或发布 APK。
- Windows CI 开启原生 HTTP 端到端测试；新增只测试、不发布的跨来源 Web CI。
- 增加真实平台安全存储集成测试，使用独立凭证键和临时账号目录，不接触用户正式登录记录；Windows CI 运行该测试。
- 教务内嵌浏览器启用私密会话，Windows 的 WebView 目录改为当前账号目录下的子目录，不再复用旧的全局教务浏览器目录；学校登录凭证不参与云端同步。真实 WebView2 Cookie 回归已验证账号间隔离及关闭后不复用登录会话。

## 本地验证

环境：Windows、Flutter 3.44.6 / Dart 3.12.2、Python 3.13、系统 Chrome。所有测试使用临时数据，不读写真实用户账号。

## 尚不能宣称完成的实机验收

1. Windows 安装版完整冷启动与所有模块恢复。原生 HTTP 测试使用凭证存储替身，平台凭证插件另有专门集成测试；两者仍不能替代安装版的完整实机使用流程。
2. Android 实机的安全存储、冷启动、离线恢复、后台切换及与 Web 交换同一账号完整数据。本轮未运行 Android 实机。
3. iOS 默认浏览器及加入主屏幕模式的持久化、重新打开、退出清理。本地 Chrome 回归不能替代 Safari / 主屏幕验收。
4. 独立公网验收 API 的部署与跨设备完整验收。正式 API 的只读探测已确认 `/healthz` 返回 200 和 `{"ok":true}`、未登录 `/v1/snapshot` 返回 401；跨来源 OPTIONS 探测返回 404，不能据此认为新 CORS 已上线。没有在正式 API 写入测试账号或数据。回环地址和临时自签 HTTPS 只验证隔离测试流程；未修改正式服务器和网站。
5. 长期 Android 密钥的实际创建、离线备份与恢复演练。历史签名密钥缺失，旧 APK 无法直接覆盖升级，必须先备份迁移；用户已决定在后续发布准备阶段处理。

上述事项保持待验收状态，不用单元测试结果替代实机或公网验证。2026-11-22 的桌面 UI 接入、759 项 Flutter 回归及真实浏览器证据另见 [桌面接入记录](desktop-garden.md)；手机新版 UI 与大模型功能仍按既定顺序后续开展。

## 复现

后端：`cd backend`，运行 `python -m unittest -v test_sync_server`。

Flutter：`cd frontend`，设置 `CAMPUS_SYNC_E2E=1`，运行 `flutter test`。原生同步专项为 `flutter test test/app/cloud/sync_e2e_test.dart`。

跨来源 Web：参照 `.github/workflows/v11-browser-reliability.yml`。API 为 `https://127.0.0.1:18444`，网页为 `https://127.0.0.1:18443`；测试浏览器只为该本机自签证书忽略证书错误，生产客户端不绕过 HTTPS 校验。

系统凭证：`flutter test integration_test/secure_session_test.dart -d windows`。Android 使用无未备份旧安装数据的专用测试设备，再替换为设备 ID；不要在保存旧数据的手机上直接运行安装测试。此项使用真实安全存储插件和临时文件，仅认证响应为测试夹具，不访问正式 API。

Windows 非 ASCII 工作路径触发本机分析服务器的 LSP 报文长度错误时，可用临时 ASCII 盘符映射运行分析；不需要改应用代码或关闭静态分析。
